Primii pași

FGO API este un API REST peste JSON. Cu el emiți și administrezi facturi, citești clienți, furnizori și articole — din aplicația ta, pentru firma ta din FGO.

Adresele mediului curent:

Mediu API Aplicația FGO
Producție https://api.fgo.ro www.fgo.ro

În producție, accesul la API depinde de abonamentul firmei. Pentru dezvoltarea integrării, folosește mediul de test, unde nu ai nevoie de abonament plătit.

1. Pregătește contul

  1. Creează-ți un cont pe www.fgo.ro sau autentifică-te dacă ai deja unul.
  2. Configurează un registru de facturi — comun sau al utilizatorului API. Seria pe care o trimiți la emitere trebuie să existe în el.
  3. Selectează firma pe care o conectezi, deschide Contul meu, apoi tabul Chei API și generează o cheie cu drepturile de care ai nevoie.

Cheia aparține firmei selectate în momentul generării și se vede o singură dată. Pune-o într-un secret manager.

Abonamentul Premium permite o cheie activă pe firmă; abonamentul Enterprise, până la 3. Cu abonamentul Premium, revocă-o pe cea veche înainte să generezi alta.

2. Fă primul apel

GET /v2/identitate îți spune dacă cheia e bună și ce drepturi are:

curl https://api.fgo.ro/v2/identitate \
  -H "Authorization: Bearer fgo_api_v1...." \
  -H "Fgo-Cod-Unic: 12345678"

Pune codul unic al firmei tale în locul lui 12345678 — numai cifrele, fără RO.

{
  "data": {
    "drepturi": ["facturi:citire", "facturi:emitere", "articole:citire"],
    "expira_la": "2026-12-31T23:59:59+02:00",
    "cautare_articol_dupa": "cod_articol"
  },
  "meta": {
    "timestamp": "2026-09-03T12:00:00+03:00"
  }
}

Răspunsul cerut se află în câmpul data.

Vezi formatul erorilor — Erori, limite și reluări.

3. Emite o factură

Înainte de apel:

  • Verifică dacă cheia are dreptul facturi:emitere.
  • Înregistrează adresa site-ului sau a magazinului în Setări eCommerce → API. Trimite adresa înregistrată în Fgo-Url-Platforma, în loc de https://magazinul-tau.ro din exemplul de mai jos.

Folosește seria din registrul configurat în FGO. Pentru valută și tipul facturii, consultă nomenclatoarele corespunzătoare. Descrierea fiecărui câmp precizează valoarea care trebuie transmisă. Cererea include clientul și cel puțin un articol; câmpurile opționale și valorile implicite sunt descrise în referință.

Cerere

curl -X POST https://api.fgo.ro/v2/facturi \
  -H "Authorization: Bearer fgo_api_v1...." \
  -H "Fgo-Cod-Unic: 12345678" \
  -H "Fgo-Url-Platforma: https://magazinul-tau.ro" \
  -H "Content-Type: application/json" \
  -d '{
    "serie": "FGO",
    "valuta": "RON",
    "tip_factura": "F",
    "client": { "tip": "PJ", "denumire": "Client Exemplu SRL", "cod_unic": "12345674", "tara": "Romania" },
    "articole": [
      { "denumire": "Servicii consultanta", "um": "ora", "nr_produse": 1, "pret_unitar": 100, "cota_tva": 0.21 }
    ]
  }'

Răspuns — 200 OK

{
  "data": { "serie": "FGO", "numar": "1201", "stocuri": [] },
  "meta": { "timestamp": "2026-09-03T12:00:00+03:00" }
}

Valorile pentru cota_tva, valuta și tip_factura le iei din nomenclatoare, care se citesc fără cheie.

Cererea completă, cu toate câmpurile și cu ce se întâmplă în spate, e în Emiterea unei facturi.
